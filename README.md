# Mapa de Luz

Projection mapping do After D'Adega: calibra superfícies pelos 4 cantos e projeta visuais que reagem à música.

- Abrir: https://mapadeluz.web.app (projeto Firebase `mapa-de-luz-f29c7`, site `mapadeluz`)
- Publicação: todo push na `main` publica automaticamente no Firebase Hosting (`.github/workflows/deploy.yml`).
- O app inteiro é um arquivo só: `public/index.html`.

## Controles
Teclado: H painel · C calibrar/show · F tela cheia · Espaço próximo visual · 1–9 superfície · Tab/setas cantos.
Controle remoto (TV Box): OK longo calibrar/show · OK próximo canto/superfície · ◀ ▶ visual · ▲ ritmo (tap tempo) · ▼ cores.
